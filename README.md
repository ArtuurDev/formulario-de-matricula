## Sobre

A pagina apresenta um formulario para matricula infantil na escola Estrelas do Amanha. O layout inclui campos para dados da crianca, endereco residencial, informacoes do responsavel, selecao de turno, escolha de esporte, envio de certidao e aceite dos termos.

## Tecnologias

- HTML
- CSS
